REST API v1

API Documentation

Public JSON API for the Cannondale Lefty model database. All endpoints return structured data you can use in any project.

Base URL List Models Model Detail Search Errors

Base URL

All API requests are relative to this base URL:

http://127.0.0.1:5000/api

Replace with the production URL when deployed.

List All Models

GET /api/models

Returns a summary of every Lefty model in the database.

Example Request curl
curl http://127.0.0.1:5000/api/models
JavaScript
const res = await fetch('http://127.0.0.1:5000/api/models'); const data = await res.json(); // data is an array of model summaries
Python
import requests res = requests.get('http://127.0.0.1:5000/api/models') data = res.json() # data is a list of dicts
Example Response
[ { "category": "lefty_ocho_xc_hardtail", "category_name": "Lefty Ocho XC Hardtail", "model": "F-Si Carbon 2", "travel_front_mm": 100, "travel_rear_mm": 0, "frame": "BallisTec Carbon...", "fork_model": "Lefty Ocho Alloy..." }, { "category": "lefty_ocho_xc_hardtail", "category_name": "Lefty Ocho XC Hardtail", "model": "F-Si Carbon 3", ... }, ... ]

Model Detail

GET /api/model/<category>/<model>

Returns full specifications for a single model. URL-encode model names with spaces.

Parameter category Category slug from the URL path
Parameter model Model name, URL-encoded
Example Request curl
curl "http://127.0.0.1:5000/api/model/lefty_ocho_xc_hardtail/F-Si%20Carbon%202"
JavaScript
const cat = 'lefty_ocho_xc_hardtail'; const model = encodeURIComponent('F-Si Carbon 2'); const res = await fetch(`http://127.0.0.1:5000/api/model/${cat}/${model}`); const data = await res.json();
Example Response
{ "category": "lefty_ocho_xc_hardtail", "category_name": "Lefty Ocho XC Hardtail", "model": "F-Si Carbon 2", "specs": { "image": "", "frame": "BallisTec Carbon, SPEED SAVE...", "fork_model": "Lefty Ocho Alloy...", "travel_front_mm": 100, "travel_rear_mm": 0, "rear_shock": "None (Hardtail)", "rear_derailleur": "Shimano XT M8100, 12-speed", "shifters": "Shimano XT M8100, 12-speed", "crankset": "HollowGram, BB30a...", "brakes": "Shimano XT M8100 hydraulic disc", "tires": "Schwalbe Racing Ray EVO...", "connectivity": "Cannondale Wheel Sensor..." } }

Search Models

GET /api/search?q=<query>

Searches model names, categories, and every spec field (frame, fork, drivetrain, brakes, etc.). Partial matches are supported.

Query Parameters

q string (required) Search term, case-insensitive
Example Requests
# Search by model name curl "http://127.0.0.1:5000/api/search?q=Scalpel" # Search by component curl "http://127.0.0.1:5000/api/search?q=SRAM%20XX1" # Search by frame material curl "http://127.0.0.1:5000/api/search?q=Hi-MOD" # Search by brake brand curl "http://127.0.0.1:5000/api/search?q=Shimano%20XTR"
JavaScript
const query = encodeURIComponent('XX1'); const res = await fetch(`http://127.0.0.1:5000/api/search?q=${query}`); const results = await res.json(); // results is an array matching the list format
Example Response (search "Carbon")
[ { "category": "lefty_ocho_xc_hardtail", "category_name": "Lefty Ocho XC Hardtail", "model": "F-Si Carbon 2", "specs": { ... } }, { "category": "lefty_ocho_full_suspension", "category_name": "Lefty Ocho Full Suspension", "model": "Scalpel Carbon 2 Lefty", "specs": { ... } }, ... ]

Error Handling

The API returns standard HTTP status codes:

200 Success Request succeeded
404 Not Found Category or model doesn't exist
400 Bad Request Missing query parameter
Error Response Format
// 404 response { "error": "Model not found" }

CORS

The API runs on Flask's development server. For production use, add CORS headers to allow cross-origin requests from your frontend. Install flask-cors and wrap the app:

from flask_cors import CORS CORS(app) # Enable all origins
